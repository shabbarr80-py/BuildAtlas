# Contributing

Use Python 3.12 and Node 22. Run API checks from `apps/api` with `pip install -e '.[dev]'`, `ruff check .`, and `pytest`. Run web checks from `apps/web` with `npm ci`, `npm run lint`, `npm run typecheck`, and `npm run build`. Keep changes scoped to the product spec and add focused tests for behavior changes. Use Conventional Commit messages.
