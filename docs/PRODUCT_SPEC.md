# Product spec

BuildAtlas turns a software idea into an evidence-backed project blueprint. It researches public GitHub repositories, analyzes requirements, and creates recommendations, an architecture diagram, risks, and an editable roadmap. It is a planning engine, not a chatbot or tools directory.

Users can register, manage projects, start analyses, inspect source evidence, update roadmap tasks, and export Markdown or JSON. Unknown data remains unknown. AI generated conclusions are identified as estimates; repository metadata is retrieved from GitHub's REST API.
